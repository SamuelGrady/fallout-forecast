# Player item animations

Equipping raises the held model and its gloved hands. Firing or using an item plays the motion below and returns to the grip. The observer sees the carried model gesture and roll during reload. Reload phases follow the holder timer, including each individual pump-shotgun shell.

| Catalog ID | Fire or use | Reload or depletion |
|---|---|---|
| service_revolver | Cylinder indexes with recoil | Support hand reaches the swung-out cylinder |
| lucky_penny_revolver | Copper cylinder indexes | Cylinder swings out and seats |
| spray_rifle | Automatic recoil | Magazine withdraws below the receiver |
| pump_shotgun | Forend racks during cooldown | Hand pushes at the loading port once per shell |
| nail_driver | Short recoil | Nail magazine slides down and reseats |
| leaky_nailgun | Short recoil | Exposed nail strip withdraws |
| hunting_rifle | Bolt slides after firing | Hand reaches the action and bolt returns |
| pressure_washer | Lance pulses with spray | Lance dips as the support hand leaves its grip |
| rock_salt | Double-barrel recoil | Barrels hinge open |
| battery_zapper | Clamps twist on discharge | Clamp assembly turns with hand reach |
| flare_launcher | Barrel kicks and charge marks count down | Empty launcher tips away after shot three |
| harpoon | Spear leaves the guide and reel turns | Automatic reload reseats the spear |
| leaf_blower | Fan spins through the burst | Hand drops and fan slows |
| disruptor | Dish sweeps while charging and firing | Dish turns and returns |
| boombox_launcher | Tube recoils | Hand reaches below the tube |
| frag | Overhand lob | Q pouch count determines next equip |
| shield_dome | Underhand toss | F pouch count determines next equip |
| umbrella | Lob with moving canopy | Returns or empties stack |
| bleach_bomb | Lob with cap movement | Returns or empties stack |
| bait_radio | Toss with antenna movement | Returns or empties stack |
| sandbag | Both hands lower and extend | Returns or empties stack |
| lightning_rod | Steep planting thrust | Returns or empties stack |
| med_tin | Raises inward and opens lid | Returns or empties stack |
| suit_patch | Hand draws patch across the suit | Returns or empties stack |
